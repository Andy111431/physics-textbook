# Physics Atlas

繁體中文大學物理教材與互動實驗。

## 網頁入口

- `textbook.html`：18 章原創精要讀本，統一章節編號。
- `index.html`：既有基礎教材、圖解與三個互動實驗。
- `expanded.html`：既有八個延伸單元。

新版讀本包含 54 節觀念、18 個詳解例題、18 題概念測驗及 18 題計算練習。每章附模型假設、三步推導、常見誤解與中英術語。這是涵蓋主要領域的教材初版，並非完整大學教科書篇幅。

## 使用方式

以任何靜態 HTTP 伺服器提供本目錄，再開啟 textbook.html。無建置步驟。

教材資料在 `textbook-data.js`，互動邏輯在 `textbook.js`，樣式在 `textbook.css`。MathJax 3 從 jsDelivr 載入，數學排版需要連線；其餘教材與導覽不依賴外部服務。CDN 不可用時公式會顯示 TeX 原文。

章節網址使用 hash，支援章節及段落連結。搜尋涵蓋中英文標題、觀念與術語。已讀狀態及主題儲存在目前瀏覽器的 localStorage；儲存不可用時仍可閱讀。已讀標記由讀者手動設定，不表示通過測驗。列印本章會展開詳解。

## 內容編輯原則

- 公式先寫模型與適用範圍，再給推導。
- 題目提供明確單位、正方向與必要的初始條件。
- 每章概念題獨立，錯答顯示正確答案與解釋。
- 新版採本站編號，與既有 Giancoli / Serway 參考章次分開。
- 延伸閱讀列出 OpenStax University Physics 三冊；本站非該書逐章翻譯。
